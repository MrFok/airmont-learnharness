# Provider marks

Used as monochrome masks at 60% opacity in provider connections and model selectors. Labels and account status retain their normal text contrast.

- ChatGPT reuses `/siwc/chatgpt-logo-white.svg` already in the project.
- Copilot: [GitHub Primer Octicons](https://github.com/primer/octicons/blob/main/icons/copilot-24.svg), MIT; see `LICENSE-octicons`.
- Grok: [LobeHub Icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/grok.svg), MIT; see `LICENSE-lobe-icons`.

Downloaded October 27, 2026. The SVG paths are unmodified. These are provider brand marks, not locally drawn substitutes.

The live model selector also uses Anthropic, OpenAI, OpenRouter, Google, DeepSeek, Ollama, Mistral, Zhipu and Azure from [LobeHub Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons), under the retained MIT license. They identify the catalog provider, including subscription/endpoint aliases, rather than inferring a vendor from the model name. Unknown providers receive a generic server symbol with their source name.
